MOMENTO Order Form — Netlify-ready MVP

1. Deploy this folder to Netlify.
2. In the Netlify project, enable Forms / form detection if prompted.
3. Submit a test order.
4. Open the site's Forms area to see the submission and uploaded files.
5. Configure a form notification email in Project configuration > Notifications.

Important MVP limit:
- Netlify Forms file uploads have an 8 MB request limit and one uploaded file per field.
- This version therefore provides 8 individual photo fields.
- Later we can replace this with a dedicated image-upload/storage flow for larger galleries.

The form uses the existing MOMENTO visual design.
